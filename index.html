Android 7+APK
⬇ Télécharger NEXUS.apk
  1. Ouvre le fichier téléchargé.
  2. Si Android bloque : Paramètres → autoriser Chrome à installer des applis.
  3. Ouvre NEXUS, tape l'adresse de ton NEXUS une seule fois, puis connecte-toi.
Android peut afficher « Application inconnue » : c'est normal, l'appli ne vient pas du Play Store.

PC Windows

Le tableau de bord complet dans sa propre fenêtre, comme un logiciel. Aucune installation : tu lances le fichier.

Windows 10 / 11 · 64 bitsEXE
⬇ Télécharger NEXUS.exe
  1. Lance NEXUS.exe.
  2. Si Windows affiche « Windows a protégé votre ordinateur » : Informations complémentaires → Exécuter quand même.
  3. Tape l'adresse de ton NEXUS une seule fois, puis connecte-toi. Ctrl+Maj+A pour la changer.

Où trouver l'adresse de mon NEXUS ?

Sur dashboard.render.com → service nexus-control → le lien bleu qui finit par .onrender.com. Le serveur gratuit peut mettre ~50 s à se réveiller au premier lancement.
